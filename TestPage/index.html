Section 1The Architecture of Screen Interaction

Section 2Visible Element Detection Rules

Paragraph 4The viewport visibility analyzer follows strict geometric rules. When an element is positioned outside the current window scroll coordinates, it is excluded from the active context payload.

Paragraph 5When an element intersects the viewport boundary, ScreenSense calculates the exact visible percentage. For instance, an element halfway off the bottom edge receives a 50% visibility score.

Section 3Deeply Scrolled Content

Paragraph 6As users scroll down the page, elements previously visible scroll above the viewport and are automatically filtered out. Only elements residing in the active viewport rectangle are transmitted.

  • Deterministic parsing: Instant command matching without LLM latency.
  • Dual-channel context: Seamless fusion of DOM and ScreenCaptureKit.
  • Spatial ordering: Elements preserve top-to-bottom reading sequence.

Paragraph 7Consider an article with 100 paragraphs. When the user scrolls to paragraph 47, ScreenSense reports paragraphs 47 through 50 as Visible Paragraphs 1 through 4, preserving spatial alignment.

Paragraph 8Furthermore, nested elements avoid redundant duplicate parent strings, ensuring that each sentence or block corresponds to its specific bounding rectangle.
